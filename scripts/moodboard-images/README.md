# Moodboard Images Instructions

Please save the following images to this directory with these exact filenames:

1. `morning-selfie.jpg` - The selfie with camera image (top left of collage)
2. `window-silhouette.jpg` - The silhouette by window with coffee (top right)
3. `washing-hands.jpg` - The washing hands in sink image (bottom left)
4. `coffee-closeup.jpg` - The close-up of coffee cup by window (bottom right)
5. `camera-selfie.jpg` - The close-up self portrait with camera (middle right)
6. `window-view.jpg` - The person looking out window image (middle left)

## How to add these images:

1. Download the images from the conversation
2. Rename them according to the list above
3. Place them in this directory (scripts/moodboard-images/)
4. Run the helper script from the project root:
   ```
   node scripts/save-images.js
   ```
5. The script will copy the images to the correct location in the public directory

## Alternative method:

You can also manually save the images directly to:
`sceneflow-app/public/images/moodboard/`

with the filenames listed above.
